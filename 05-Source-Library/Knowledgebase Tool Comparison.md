# Knowledgebase Tool Comparison

## Core Idea
This page evaluates possible display/editing/RAG layers for the Markdown/Git AI agency knowledgebase.

## Apps to Research
- Wiki.js
- BookStack
- DokuWiki
- Outline
- MediaWiki
- Obsidian synced through Git
- Joplin Server
- Anytype
- Logseq
- Open-source RAG tools
- Markdown knowledgebase tools
- MCP-compatible knowledgebase tools
- Lightweight vector database options

## Evaluation Criteria
- Docker support
- Markdown support
- Git sync
- Search quality
- Ease of editing
- AI/RAG friendliness
- Backup simplicity
- Mobile usability
- Complexity level for a home server
- Fit for a daily AI-curated knowledgebase

## Current Working Default
Markdown files in Git are the durable source of truth. A display layer can be added later without locking the knowledgebase into a database-first system.
